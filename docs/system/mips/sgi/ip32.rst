.. _sgi-ip32:

================
SGI IP32: O2
================

The O2 is a Silicon Graphics entry workstation. A published hardware
page dates it to 1996 as the successor of the Indy and names its chips
as CRIME, MACE and GBE (:src:`bukosek-sgi-o2 Architecture`), *observed*.
It keeps memory, graphics and I/O data in one pool of main memory
(:src:`o2-technical-report p. 4`), *established*. The CRIME 1.5 specification
gives CRIME's roles (:src:`sgi-crime-1.5-spec Table 3-1, PDF p. 48`),
*established*.

The technical report lists the R5000 and R10000
(:src:`o2-technical-report Table 2-1`), *established*. The same
hardware page lists five processor families, RM5271 (RM5200 family),
R5000, RM7000, R10000 and R12000 (:src:`bukosek-sgi-o2 Processor
options`), *observed*. No bootable O2 machine exists. Facts are rated as
described in :ref:`sgi-ratings`.

.. _sgi-ip32-current:

Current model
=============

QEMU provides one O2 machine, ``o2-test`` (``hw/mips/sgi/o2.c``). It is a
synthetic register test profile that gives the qtests of the O2 chips a
board to run on. It is not a machine that boots an operating system, and
no functional test boots one on it. By default it fits:

- one R10000 at a fixed 195 MHz, the only processor it accepts;
- 64 MiB of RAM, with 128 MiB or, in the eight-bank profile, 1 GiB as
  options;
- CRIME, the MACE host bridge with its two serial ports and real-time
  clock, and the MACE Ethernet MAC with no PHY;
- two AIC-7880 SCSI controllers at PCI device 1 and 2.

GBE, the boot flash and the PHY are options. Each chip's page describes
the device, what the profile does with it and how it is tested.

.. _sgi-ip32-published:

Published machines
==================

Three published sources show real O2s. Each is rated *observed*.

- An OpenBSD 5.2 boot report of an O2 with a 195 MHz R10000 revision 2.7
  and a 1024 KB secondary cache (:src:`dmesgd-2432 cpu0`). It shows CRIME
  revision 10.1, a MACE PCI bridge revision 1, the MAC-110 revision 1
  with a DP83840 PHY at MII address 8, an AD1843 revision 1 and GBE
  revision 1.
- A NetBSD 9.99.31 boot report of an O2 with an R12000
  (:src:`dmesgd-5290 cpu0`). It shows a CRIME ID of ``0x1000000000a1``
  (NetBSD prints it in decimal, 17592186044577, converted here),
  a MACE PCI bridge revision 1 and a DP83840 PHY at MII address 8.
- A published hardware inventory of an O2 with a 300 MHz R5000-family
  processor (:src:`bukosek-sgi-o2 My O2`).

The profile's defaults differ from these. These are model limits:

.. list-table::
   :header-rows: 1

   * - Item
     - Published machines
     - ``o2-test`` default
   * - CRIME ID low byte
     - ``0xa1``
     - ``0xb1``, the value in the CRIME 1.5 specification
       (``crime-profile=legacy-software`` returns ``0xa1``)
   * - Ethernet PHY
     - DP83840 at MII address 8
     - none; an ICS1890 is an option
   * - R10000 revision
     - 2.7
     - 2.6
   * - Processors
     - R5000, RM5271, RM7000, R10000 and R12000 modules
     - R10000 at 195 MHz only
   * - Parallel port
     - fitted
     - absent

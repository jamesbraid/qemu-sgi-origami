# How tests/qtest/meson.build splits sn0-origin2000-kona-fill-test into
# separate tests, qtest-mips64/sn0-origin2000-kona-fill-test-GROUP, which
# meson runs at once. Each line is a group and a GLib test path: one case,
# or a suite whose cases directly under it all join the group. A suite whose
# case names the source builds from a printf template joins a group whole,
# by its own line. Every case and suite the source registers must be in
# exactly one group, which scripts/check-qtest-registered.py checks, so a
# new case or suite needs a line here.
#
# The groups are areas: X boxes, clips, cursors and the semantic desktop
# (box), the semantic GX truth tables (semantic), X points (point) and X
# lines and segments (line).

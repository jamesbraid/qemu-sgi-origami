# How tests/qtest/meson.build splits sn0-origin2000-kona-3d-test into
# separate tests, qtest-mips64/sn0-origin2000-kona-3d-test-GROUP, which meson
# runs at once. Each line is a group and a GLib test path: one case, or a
# suite whose cases directly under it all join the group. A suite whose case
# names the source builds from a printf template joins a group whole, by its
# own line. Every case and suite the source registers must be in exactly one
# group, which scripts/check-qtest-registered.py checks, so a new case or
# suite needs a line here.
#
# The groups are areas: shared-renderer cases drawn with the host renderer
# (renderer, and its fragment tests in renderer-fragment) and with it
# unavailable (renderer-cpu and renderer-cpu-fragment), texturing (texture,
# and texture-formats for the per-format and per-source suites), pixel
# reads, pixel drawing and copies, colour index, and the rest of the GL
# state.
